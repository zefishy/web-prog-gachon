Base format: random joke fetcher

Every exercise in this week is the same six lines in a different costume. This page is that skeleton, left deliberately unfinished: the request works and logs the data, and the four TODO steps are where your own rendering goes.

Press the button — the data lands in the console, not on the page yet.

Your job: fill the two lines below

 

 

What is already done

  1. The button is wired to an async function.
  2. fetch() sends the request and response.ok is checked before anything is parsed.
  3. await response.json() turns the body into an object.
  4. Errors are caught and written to the status line, so a dead API does not fail silently.

Open the console before pressing the button: console.log(data) prints the whole object, and the field names you need are inside it. That habit removes most of the guessing from any API exercise.
