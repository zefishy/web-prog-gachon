Seoul weather dashboard

Open-Meteo needs no API key: you send a latitude and longitude and it sends back the current weather. This one is pinned to Gachon's campus in Seongnam.

Press the button to load the current conditions.

Seongnam, Gyeonggi

Conditions
Wind
Observed

The request is https://api.open-meteo.com/v1/forecast?latitude=37.45&longitude=127.13&current_weather=true — the same shape as any other API call, just with the query string doing the configuration.
