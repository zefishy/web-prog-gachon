Homework 1 — Personal portfolio

The Week 9 homework: a personal portfolio repo on GitHub called portfolio, built week by week with semantic HTML, responsive CSS themed to match this course library, and a light/dark theme toggle that remembers your choice.

The repo

github.com/zefishy/wp-gachon-homework

A single-page portfolio for Ryan Wong, exchange student at Gachon University (K0126002 Web Programming · 2026 Fall · Dr. Toshpulatov). Branch main, clean history, pushed to the remote.

Open portfolio repo

What's on the page

  • Hero — name, photo (placeholder avatar), role, and bio, all drawn from the profile file
  • Course projects — three cards: Book Search App (week 7), Registration form with JS validation (week 8), and the Team 16 Gachon Wind proposal
  • Skills — grouped chips: markup/styling/scripting, design & layout, quality & workflow
  • About — role, field, focus, interests, and goal from the profile

The commits

Eleven meaningful commits with lecture-style messages, so the history tells the build story:

  • Initial commit: add README and .gitignore
  • Add semantic HTML page structure
  • Add hero section with photo and bio
  • Add project cards for course projects
  • Add skills section
  • Add about section with profile details
  • Style the page with the course library theme
  • Add dark mode toggle with saved preference
  • Fix layout on narrow screens and honor reduced motion
  • Fix favicon data URI encoding so the HTML validates
  • Document GitHub Pages deployment and the accessibility checklist

Theming — same as the course library

Dark green default (#092328 → #8BBB92) with a light theme behind the header switch. The switch cross-fades the colour tokens and saves the choice in localStorage. Narrow-phone rules stack the cards and stretch the buttons; reduced motion turns the transitions off.

Note: img/avatar.svg is a stand-in (green "RW" initials). Swap it for a real photo in the portfolio repo before submitting.
