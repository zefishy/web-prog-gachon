Homework 2 — Deploy on GitHub Pages

Deploy the portfolio from Homework 1 on GitHub Pages, then submit the live URL plus a Lighthouse Accessibility screenshot on Cybercampus.

Task

Deploy github.com/zefishy/wp-gachon-homework (branch main) on GitHub Pages and hand in:

  • the GitHub Pages live URL, and
  • a Lighthouse Accessibility screenshot (score must be ≥ 90)

Source: Deployment lecture, "Summary & Next Steps" slide.

Steps

  1. Push the portfolio repo to GitHub with branch name main — done (repo).
  2. On the repo page: Settings → Pages → Build and deployment → Source: "Deploy from a branch", branch main, folder /(root), then Save.
  3. Wait about a minute. The site goes live at https://zefishy.github.io/portfolio/.
  4. Run Lighthouse on the live URL: DevTools → Lighthouse → category Accessibility → Mobile → Analyze. Save the screenshot.
  5. Submit the live URL + screenshot on Cybercampus.

Homework 2 checklist

#RequirementStatus
1 Semantic HTML — <header>, <nav>, <main>, <footer>, labelled sections Done
2 Responsive CSS — mobile-first, narrow-phone rules at ≤ 36 rem Done
3 At least one JS interaction — light/dark toggle with saved preference Done
4 Lighthouse Accessibility score ≥ 90 — screenshot required Pending
5 Every image has meaningful alt text Done
6 Color contrast passes WCAG AA Done

Contrast was computed from the theme tokens: worst pair ≈ 6.6:1 in both themes (AA requires 4.5:1 for normal text). Lighthouse must be run on the live URL after Pages is enabled — the screenshot is what goes to Cybercampus.
