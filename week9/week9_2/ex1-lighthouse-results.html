Week 9_2 — Exercise 1

Run a Lighthouse performance audit and read the results — First Contentful Paint, Largest Contentful Paint, Total Blocking Time, Cumulative Layout Shift, and Speed Index.

Exercise 1 — Read the Lighthouse Results

Lighthouse measures performance with scores from 0–100. A score of 90+ means “Good” — it does not guarantee sub-1-second load time. The Core Web Vitals below are what the score is based on.

Metric First Contentful Paint FCP
Metric Largest Contentful Paint LCP
Metric Total Blocking Time TBT
Metric Cumulative Layout Shift CLS
Metric Speed Index SI
Good (>90) FCP ≤ 1.8s ≤ 1.8s
Good (>90) LCP ≤ 2.5s ≤ 2.5s
Good (>90) TBT ≤ 200ms ≤ 200ms
Good (>90) CLS ≤ 0.1 ≤ 0.1
Good (>90) SI ≤ 3.4s ≤ 3.4s

Why these metrics matter

  • FCP — When the first text or image is painted. Users need to see something happening immediately.
  • LCP — When the largest visible element (usually the hero image or heading) finishes loading. This is the main “is it useful yet?” signal.
  • TBT — How long the main thread is blocked by scripts between FCP and TTI. High TBT means the page feels unresponsive to clicks.
  • CLS — How much the page layout jumps around as images and ads load. Set width/height on images to reserve space.
  • SI — How quickly the visible parts of the page are populated. Lower is better.
