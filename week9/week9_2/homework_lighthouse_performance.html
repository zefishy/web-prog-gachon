Homework: Lighthouse performance

The homework in four steps, how to do it, and the lecturer’s 10-item performance checklist to tick off.

The homework

Set at the end of the performance lecture. The slide reads:

Optimize your personal site: (1) Run Lighthouse, screenshot your Performance score. (2) Apply at least 3 optimizations from today. (3) Re-run Lighthouse, screenshot new score. Post both screenshots to your page with a 2-sentence description of what you changed.

Performance slides — Summary & Homework

That is four jobs, in this order:

  1. Measure. Run Lighthouse on your personal site and screenshot the Performance score.
  2. Fix. Apply at least three optimisations from the lecture.
  3. Measure again. Re-run Lighthouse and screenshot the new score.
  4. Post. Put both screenshots on your page, with a two-sentence description of what you changed.

How to do it

  • Serve the page from a local server, not a file:// path, so the result is the same on every run. python3 -m http.server is enough.
  • Open it in a private window with extensions off, because extensions add their own requests and skew the score.
  • In DevTools, open the Lighthouse tab, tick only Performance, choose Navigation and one device (mobile or desktop), then Analyze page load. Use the same settings for both runs.
  • Take the “before” screenshot and save the numbers before editing anything. Scores wobble a little between runs, so run twice and note it if they differ.
  • Pick your three fixes from the checklist below. The Diagnostics section of the report tells you which ones apply to your page; the fix-the-slow-page exercise shows each as a before and after.
  • Write the two sentences last: the first says what you changed, the second says what moved and by how much.
