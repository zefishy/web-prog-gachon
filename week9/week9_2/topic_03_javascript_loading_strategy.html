JavaScript loading strategy

Where the script sits, and when it runs.

A plain script blocks parsing while it downloads. async downloads in parallel and runs as soon as it arrives, in no fixed order. defer downloads in parallel and runs after parsing, in document order.

AttributeBlocks parsingOrder keptRuns
noneYesYesImmediately
asyncNoNoAs soon as loaded
deferNoYesAfter parsing

Use defer for anything that touches the DOM.

The code

<script src="app.js" defer></script>
<script src="analytics.js" async></script>
