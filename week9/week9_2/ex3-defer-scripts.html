Exercise 3 — Defer Scripts

A <script> in <head> blocks HTML parsing until it downloads and runs. Adding defer downloads it in parallel and runs after the DOM is ready — preserving script order and keeping the page interactive.

Before — blocks parsing

<script src="https://cdn.tailwindcss.com"></script>

Browser stops parsing HTML until the script downloads and runs.

After — non-blocking

<script src="app.js" defer></script>

Download happens in parallel; script runs after HTML is parsed.

defer vs async

  • defer — Downloads in parallel, runs after HTML is parsed, preserves script order. Best for most scripts that depend on the DOM.
  • async — Downloads in parallel, runs immediately when downloaded, order not guaranteed. Best for independent scripts like analytics.
  • Neither — Blocks HTML parsing until the script downloads and runs. Avoid unless the script must run before any HTML renders.
