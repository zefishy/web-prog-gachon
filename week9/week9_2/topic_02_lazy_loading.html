Lazy loading

Do not download what nobody has scrolled to.

loading="lazy" is a native attribute: the browser decides when to fetch, and it needs no JavaScript. Reserve it for images below the fold — the hero image should load eagerly.

Always set width and height so the space is reserved and the layout does not jump when the image arrives.

The code

<!-- Below the fold -->
<img src="gallery-1.jpg" alt="Studio interior"
     width="640" height="420" loading="lazy">

<!-- Above the fold: leave it eager -->
<img src="hero.jpg" alt="Campus at dusk" width="1200" height="600">
