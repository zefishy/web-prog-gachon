Add defer to scripts

A live page that records the order its own scripts ran in. Blocking, defer, async and module scripts, side by side.

Live demo: what order did the scripts run in?

This page has seven scripts in its <head>. Each one records the document’s readyState, whether the results table already existed in the DOM, and the time. When the page has finished loading, the list below is filled in from those records, in the order the scripts really ran in your browser.

The times are performance.now() readings and change on every reload. The async rows may move up or down between runs, which is the point: async has no guaranteed position.

How to read the table

  • Blocking scripts run with readyState loading and the table is not in the DOM yet. A script that touches the page there would fail.
  • Defer scripts wait until parsing is done: interactive, table present, and they keep their written order.
  • Async scripts run when their download finishes, so they can land while the page is still loading or after it is interactive.
  • All of them hold up the load event, but only blocking scripts hold up the first paint.

Why the inline scripts act differently

defer and async are ignored on an inline classic script (one with no src). The browser has nothing to download, so it runs the code on the spot. The same attributes do work on external files, which is why this page loads three tiny scripts from data: URLs, and on inline type="module" scripts: modules are deferred automatically, and async makes them run as soon as ready. 

<!-- blocking: runs now, parser waits -->
<script src="app.js"></script>

<!-- defer: downloads in parallel, runs after parsing, in order -->
<script src="app.js" defer></script>

<!-- async: downloads in parallel, runs the moment it arrives, any order -->
<script src="analytics.js" async></script>

<!-- inline classic: defer and async are ignored, it runs immediately -->
<script defer>doSomething()</script>

<!-- inline module: deferred automatically; async makes it run as soon as ready -->
<script type="module">doSomething()</script>
<script type="module" async>doSomething()</script>

Try it

  1. Reload a few times and watch which rows keep their position and which move.
  2. View the page source and delete defer from the external defer script. Reload: its readyState changes to loading, because without the attribute it blocks like any classic script.
  3. Open the Performance tab, record a reload, and find the Scripting block for each script.
