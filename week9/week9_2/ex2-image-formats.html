Exercise 2 — Image Formats

Images are usually the largest resource on a page. Choosing the right format and serving it at the right size can cut load time by half or more. WebP typically beats JPEG and PNG by 25–35% while supporting both lossy and lossless compression.

Format Best for Transparency Notes
JPEG Photographs, complex images No Smallest for photos; lossy compression
PNG Transparency, logos, line art Yes Lossless but larger; use when transparency is needed
WebP Photos + transparency Yes 25–35% smaller than JPEG/PNG; modern browsers (2020+)

Key rules

  • Serve images at the size they are displayed, not the original camera size. A 4000×3000 photo shown in a 400×300 thumbnail is wasted bandwidth.
  • Always set width and height on <img> tags so the browser can reserve space — this prevents Cumulative Layout Shift (CLS).
  • Use loading=“lazy” on below-fold images so they don’t compete with above-fold content.
  • Use “eager” for hero images — the largest image above the fold should load immediately.
