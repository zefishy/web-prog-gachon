Week 9_1 — Exercise 3

Run a Lighthouse accessibility audit and fix every failing audit. All four common issues are demonstrated and fixed here.

Exercise 3 — Lighthouse Accessibility Fixes

Four common accessibility failures are shown below — each one is what Lighthouse flags, and each has a fix applied.

Audit Problem Fix
label-content-name-mismatch Shelf spine text says “JS” but aria-label says “JavaScript” Remove redundant aria-label so the accessible name is the visible text
label Form input without a label Add <label for="email-field"> attached to the input
color-contrast Gray text on white below 4.5:1 contrast Darken text to at least 4.5:1 contrast ratio
skip-link No skip-to-content link for keyboard users Add a skip link as the first element in <body>

A registration form with all accessibility fixes applied. Tab through it to verify keyboard navigation works.
