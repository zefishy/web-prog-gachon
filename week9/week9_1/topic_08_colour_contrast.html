Colour contrast

A ratio, not an opinion.

Contrast is computed from the relative luminance of the two colours. Below 4.5:1 body text fails AA; large text (18.66px bold or 24px) needs 3:1.

#767676 on white — 4.54:1, passes AA for body text.

#949494 on white — 3.03:1, fails AA for body text, passes for large text.

White on #1a56db — 6.18:1, passes AA.

The ratios above are computed, not estimated.

The code

/* AA: 4.5:1 body text, 3:1 large text */
body { color: #767676; background: #ffffff; }  /* 4.54:1 */

/* Fails AA for body text */
.muted { color: #949494; }                     /* 3.03:1 */
