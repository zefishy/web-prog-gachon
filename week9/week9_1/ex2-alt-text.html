Week 9_1 — Exercise 2

Supply meaningful alt text for images: informative images describe content, decorative images use an empty alt, and functional images describe the action.

Exercise 2 — Alt Text on Images

Screen readers announce the alt text of every image. Informational images need a description; decorative images need alt="" so they are skipped; functional images describe the action.

Informational Campus building photo Describes content and purpose
Decorative Wavy divider image Empty alt
Functional University logo in link Describes action

Never write

  • “image of…” or “photo of…” — screen readers already announce “image”
  • “image” or “logo” alone — too generic, wastes attention
  • “img_0347.jpg” — raw filenames are unusable
