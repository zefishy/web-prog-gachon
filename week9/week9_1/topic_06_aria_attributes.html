ARIA attributes

Names, descriptions and state — when HTML runs out.

aria-label replaces a missing visible name. aria-describedby points at a longer description. aria-expanded reports whether a disclosure is open, and must be updated by script.

This panel is controlled by the button above, which reports its state through aria-expanded.

ARIA never adds behaviour. It only changes what is announced.

The code

<button aria-expanded="false" aria-controls="panel">Details</button>
<div id="panel" hidden>...</div>

<script>
  btn.setAttribute('aria-expanded', isOpen);
</script>
