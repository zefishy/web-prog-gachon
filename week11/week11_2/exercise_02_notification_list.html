Notification list

A list rendered from data. NotificationList maps an array to one NotificationItem per entry, and each item picks its own icon from its type prop.

The task

Given an array of notification objects [{ id, type, message }], render each as a styled item. Show a checkmark icon for type === 'success', a warning icon for type === 'warning', and a default icon otherwise. Use conditional rendering.

The components

NotificationList.jsx

const notifications = [
  { id: 1, type: 'success', message: 'Profile updated successfully' },
  { id: 2, type: 'warning', message: 'Password expires in 3 days' },
  { id: 3, type: 'info',    message: 'New lecture materials available' },
];

function NotificationItem({ type, message }) {
  const icon = type === 'success' ? '✅' : type === 'warning' ? '⚠️' : 'ℹ️';
  return (
    <li>{icon} {message}</li>
  );
}

function NotificationList() {
  return (
    <ul>
      {notifications.map(n => (
        <NotificationItem key={n.id} type={n.type} message={n.message} />
      ))}
    </ul>
  );
}

How it works

  • .map() turns data into elements. Each object in notifications becomes one <NotificationItem />, so adding a fourth notification means adding a fourth object, not more JSX.
  • The key comes from the data. key={n.id} lets React match items between renders. It uses the stable id, not the array index, and React keeps it for itself: NotificationItem never receives it as a prop.
  • A chained ternary picks the icon. 'success' gets ✅, 'warning' gets ⚠️, and anything else, including 'info', falls through to ℹ️.
  • The item gets only what it shows. It receives type and message, not the whole object, so its props say exactly what it depends on.
