Student profile card

The Friday homework, Task 11-A: one StudentProfileCard component with five props, used to build a student directory. The card below carries my real student ID.

The task

Build a StudentProfileCard component that accepts props and renders a formatted profile card. The card must display your real student ID so your submission is uniquely yours.

  • Exactly five props: name, studentId, major, year and gpa, all used in the returned JSX.
  • Your real student ID visible in the rendered output.
  • Custom CSS for the card: border, padding, border-radius, a background different from the page, and a hover effect.
Lecturer’s Friday Task 11-A — React Components & Props

The task asks for three cards, mine plus two classmates. This page shows only mine.

The component

StudentProfileCard.jsx and App.jsx

function StudentProfileCard({ name, studentId, major, year, gpa }) {
  return (
    <div className="profile-card">
      <div className="card-header">
        <h2 className="student-name">{name}</h2>
        <span className="student-id">ID: {studentId}</span>
      </div>
      <div className="card-body">
        <p><strong>Major:</strong> {major}</p>
        <p><strong>Year:</strong> {year}</p>
        <p><strong>GPA:</strong> {gpa}</p>
      </div>
    </div>
  );
}

function App() {
  return (
    <div>
      <h1>Student Directory</h1>
      <StudentProfileCard
        name="Ryan Wong"
        studentId="202699476"
        major="Computer Engineering"
        year={2}
        gpa={3.8}
      />
    </div>
  );
}

How it works

  • Five destructured props. { name, studentId, major, year, gpa } takes each value out of the props object, so the JSX uses plain names. Every one of them appears in the returned markup.
  • Strings and numbers. name and major are string attributes. year={2} and gpa={3.8} use braces so they arrive as numbers.
  • Reuse. The card knows nothing about whose data it shows. Another student is one more <StudentProfileCard /> with different props, with no change to the component.
  • The styling. The border, padding, rounded corners, tinted background and hover lift come from week11.css and use the site’s own colour tokens. The hover effect is turned off for visitors who ask for reduced motion.
  • CDN instead of Vite. The task builds a Vite project and deploys it to GitHub Pages. This page loads React and Babel from a CDN so it runs as a static file. The component is the same, but the Vite project and the GitHub Pages deploy are not part of this page.
