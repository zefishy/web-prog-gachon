Week 11_2 · Exercise 4

Course catalog

The Friday practice challenge, which uses the whole week: an array of data, a list rendered with .map(), props passed to a card, and a badge chosen by a boolean.

The task

Create a small React app with the following components:

  • A CourseCard component that receives title, instructor, credits, and required (boolean) as props
  • If required is true, show a red “필수” badge; otherwise show a grey “선택” badge
  • A CourseCatalog component that maps over this array and renders a CourseCard for each

Start with static JSX, then extract into components, then add props.

The components

CourseCard.jsx

function CourseCard({ title, instructor, credits, required }) {
  return (
    <div className="card">
      <h3>
        {title}{' '}
        <span className={required ? 'badge badge-required' : 'badge badge-elective'} lang="ko">
          {required ? '필수' : '선택'}
        </span>
      </h3>
      <p>Instructor: {instructor}</p>
      <p>Credits: {credits}</p>
    </div>
  );
}

CourseCatalog.jsx

const courses = [
  { id: 1, title: 'Web Programming', instructor: 'Dr. Toshpulatov', credits: 3, required: true },
  { id: 2, title: 'Database Systems', instructor: 'Dr. Kim', credits: 3, required: true },
  { id: 3, title: 'Mobile App Dev', instructor: 'Dr. Lee', credits: 2, required: false },
];

function CourseCatalog() {
  return (
    <div>
      <h2>Course Catalog</h2>
      {courses.map(course => (
        <CourseCard
          key={course.id}
          title={course.title}
          instructor={course.instructor}
          credits={course.credits}
          required={course.required}
        />
      ))}
    </div>
  );
}

week11.css (badge colours)

.badge-required { background: var(--danger); color: var(--on-danger); }
.badge-elective { background: var(--muted);  color: var(--paper); }

How it works

  • One boolean, two decisions. required picks both the badge text (필수, required, or 선택, elective) and its class name, so the colour and the label always agree.
  • Each course becomes four props. CourseCatalog passes the fields one by one, as the brief lists them. {...course} would also work, but it would pass id too.
  • The colours come from the theme. The brief asks for red and grey. White text on a typical red such as #e53935 is 4.23:1, and on #9e9e9e grey 2.68:1, both under the 4.5:1 WCAG AA minimum. The badges use the site’s danger and muted colours instead, which pass in both themes.
  • lang="ko" on the badge tells screen readers to read the label as Korean, not as English.
