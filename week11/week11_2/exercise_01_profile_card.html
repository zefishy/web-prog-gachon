Week 11_2 · Exercise 1

Profile card

One component, four props. Three are required. avatarUrl has a default value, so the card still shows a picture when the parent leaves it out.

The task

Create a ProfileCard component that accepts name, role, email, and optional avatarUrl (default: a placeholder image). Render a card showing all four fields. Use default prop for avatarUrl.

Lecturer’s Friday study guide — Practice exercise 1

The component

ProfileCard.jsx

function ProfileCard({ name, role, email, avatarUrl = 'https://via.placeholder.com/80' }) {
  return (
    <div style={{ border: '1px solid #ccc', borderRadius: 8, padding: 16, maxWidth: 300 }}>
      <img src={avatarUrl} alt={name} style={{ borderRadius: '50%', width: 80 }} />
      <h2>{name}</h2>
      <p>{role}</p>
      <a href={`mailto:${email}`}>{email}</a>
    </div>
  );
}

function App() {
  return (
    <ProfileCard
      name="Dr. Toshpulatov"
      role="Professor"
      email="muhiddin@gachon.ac.kr"
    />
  );
}

How it works

  • Destructured props. { name, role, email, avatarUrl } takes the four values out of the props object, so the JSX reads {name} instead of {props.name}.
  • The default value. avatarUrl = 'https://via.placeholder.com/80' is ordinary destructuring default syntax. App passes no avatarUrl, so the placeholder is what renders.
  • One prop, two uses. href={`mailto:${email}`} builds the link target from the same email prop that fills the link text.
  • Inline styles are objects. style={{ ... }} is a JavaScript object inside JSX braces, and bare numbers such as padding: 16 are read as pixels.
