Card children

A wrapper component. Card draws the box and the heading. Whatever sits between <Card> and </Card> arrives as children and is placed inside it.

The task

Create a reusable Card component that accepts a title prop and renders any children inside a styled box. Use it to wrap two different content sections.

Lecturer’s Friday study guide — Practice exercise 3

The component

Card.jsx

function Card({ title, children }) {
  return (
    <div style={{
      border: '1px solid #bae6fd',
      borderRadius: 10,
      padding: '16px 20px',
      marginBottom: 16
    }}>
      <h3 style={{ marginBottom: 10 }}>{title}</h3>
      {children}
    </div>
  );
}

function App() {
  return (
    <>
      <Card title="Lecture Topics">
        <ul>
          <li>Components</li>
          <li>Props</li>
        </ul>
      </Card>
      <Card title="Homework">
        <p>Build a student portfolio component</p>
      </Card>
    </>
  );
}

How it works

  • children is a prop like any other. React fills it with the JSX written between the opening and closing tags, and Card renders it with {children}.
  • Card does not know what it holds. The first card wraps a list and the second a paragraph. The box and heading code is written once.
  • A fragment as the root. App returns two cards side by side, and <>…</> groups them without adding an extra <div> to the page.
