Week 11_1 · Exercise 1

Student card

The Monday lab: fill in four blanks so StudentCard renders the name, ID and major it is given. The card below shows my own student ID, as the lab asks.

The task

Fill in the blanks to complete this component:

function StudentCard( ____ ) {
  return (
    <div className="card">
      <h2>{____}</h2>
      <p>ID: {____}</p>
      <p>Major: {____}</p>
    </div>
  );
}

It should work when used like this: <StudentCard name="Alice" id="20231234" major="CS" />

In-class task: fill in the blanks and test it in Vite. Your rendered card must show your own student ID in the output. Take a screenshot.

Lecturer’s Monday visual lecture — Lab challenge

The component

StudentCard.jsx

function StudentCard({ name, id, major }) {
  return (
    <div className="card">
      <h2>{name}</h2>
      <p>ID: {id}</p>
      <p>Major: {major}</p>
    </div>
  );
}

function App() {
  return <StudentCard name="Ryan Wong" id="202699476" major="Computer Engineering" />;
}

How it works

  • The first blank is the props object. Writing { name, id, major } in the parameter list destructures it, so the three values are plain variables inside the function.
  • The other three blanks are those names in braces. {name}, {id} and {major} are JavaScript expressions dropped into the JSX.
  • id is only a prop name here. It never reaches an element, so it does not become an HTML id attribute.
  • CDN instead of Vite. The lab runs the component in a Vite project. This page loads React and Babel from a CDN so it works as a static file; the component itself is unchanged.
