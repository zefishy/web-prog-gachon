Page title sync

An effect that talks to something outside React: the browser tab. Whatever is typed becomes the tab title, and the cleanup puts it back when the component goes away.

The task

Build a component with a text input. Use useEffect to update document.title to show whatever is typed in the input. Revert the title to “WebPro” when the component unmounts (via cleanup).

Lecturer’s Friday study guide — Practice exercise 1

Type, then watch the browser tab. The Unmount button removes the component so the cleanup can be seen running.

The component

TitleEditor.jsx

function TitleEditor() {
  const [text, setText] = useState('');

  useEffect(() => {
    document.title = text || 'WebPro';
    return () => { document.title = 'WebPro'; };
  }, [text]);

  return (
    <input
      value={text}
      onChange={e => setText(e.target.value)}
      placeholder="Type to change tab title…"
      aria-label="Tab title"
    />
  );
}

function Demo() {
  const [shown, setShown] = useState(true);
  return (
    <div>
      <button onClick={() => setShown(s => !s)}>
        {shown ? 'Unmount TitleEditor' : 'Mount TitleEditor'}
      </button>
      {shown ? <TitleEditor /> : <p className="muted">Unmounted: the cleanup set the title back to “WebPro”.</p>}
    </div>
  );
}

How it works

  • document.title is outside React, so changing it is a side effect. It belongs in useEffect, not in the render.
  • [text] re-runs the effect on every keystroke, and only then. Other re-renders leave the title alone.
  • The cleanup runs twice in this component’s life: before each new run, and on unmount. On unmount it is what resets the title to “WebPro”.
  • The Demo wrapper with the Unmount button is mine, in the same style as the lecturer’s demo pages; the TitleEditor itself is the study guide’s.
