Effect syntax: mount and cleanup

The shape of every effect: a function that runs after render, and an optional function it returns. Mount and unmount the component below and watch what lands in the log.

The task

Press Unmount and Mount and watch the log: the effect runs after the first render, and the cleanup runs when the component is removed.

The effect is useEffect(() => { … return () => { … }; }, []). Code comment from the slides: “Runs after the first render (empty dependency array)”.

Week 12 Friday slides — useEffect syntax

The slides print to console.log. Here the same two messages go to the “Effect log” below the buttons, so they can be seen without opening the console.

The component

MyComponent.jsx

function MyComponent({ onLog }) {
  const [data] = useState(null);

  useEffect(() => {
    // Runs after the first render (empty dependency array)
    onLog('Component rendered!');

    // Optional: return a cleanup function
    return () => {
      onLog('Cleanup before next run or unmount');
    };
  }, []);

  return <p>MyComponent is mounted. data = <code>{JSON.stringify(data)}</code></p>;
}

function Demo() {
  const [shown, setShown] = useState(true);
  const [lines, setLines] = useState([]);
  const log = text => setLines(l => [...l, text]);

  return (
    <div>
      <button onClick={() => setShown(s => !s)}>
        {shown ? 'Unmount MyComponent' : 'Mount MyComponent'}
      </button>
      <button onClick={() => setLines([])}>Clear log</button>

      {shown ? <MyComponent onLog={log} /> : <p className="muted">MyComponent is not on the page.</p>}

      <h3>Effect log</h3>
      <div role="log" aria-label="Effect log">
        {lines.length
          ? <ul>{lines.map((line, i) => <li key={i}>{line}</li>)}</ul>
          : <p className="muted">Nothing logged yet.</p>}
      </div>
    </div>
  );
}

How it works

  • The effect runs after the first render. The paragraph is already on screen when “Component rendered!” is logged, which is why effects are the right place for work that touches the outside world.
  • [] means once. Logging a line or clicking Clear re-renders Demo, and with it MyComponent, but the effect does not run again because it has no dependencies that could change.
  • The returned function is the cleanup. React calls it when the component is removed, and also before the effect runs again if there were dependencies. With [] that means only on unmount. Press Unmount and the second line appears.
  • Mount again and you get a fresh run. An unmounted component loses its state; the log shows “Component rendered!” once more because it is a new mount.
  • Only the log lives in Demo. The slides’ MyComponent has no props; I pass onLog in so the messages can be shown on the page instead of the console. onLog is not in the dependency array, which is safe here because it only calls a state setter.
