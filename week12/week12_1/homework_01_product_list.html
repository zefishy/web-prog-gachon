Shopping cart, step 1: Product list

The data the whole cart is built on: five products, each with a name, a price and an image URL. No state yet, only an array rendered with map.

The code

ProductList.jsx

const PRODUCTS = [
  { id: 1, name: 'Wireless Earbuds',    price: 89000,  image: 'img/earbuds.jpg' },
  { id: 2, name: 'Mechanical Keyboard', price: 129000, image: 'img/keyboard.jpg' },
  { id: 3, name: 'USB-C Hub',           price: 45000,  image: 'img/usb-hub.jpg' },
  { id: 4, name: 'Laptop Stand',        price: 39000,  image: 'img/laptop-stand.jpg' },
  { id: 5, name: 'HD Webcam',           price: 72000,  image: 'img/webcam.jpg' },
];

const won = n => n.toLocaleString('ko-KR') + ' KRW';

function ProductList({ products }) {
  return (
    <ul className="product-grid">
      {products.map(p => (
        <li key={p.id}>
          <img src={p.image} alt="" width="320" height="200" />
          <h3>{p.name}</h3>
          <p className="price">{won(p.price)}</p>
        </li>
      ))}
    </ul>
  );
}

Notes

  • Five items, three fields each, plus an id so every later step has a stable key.
  • The image is a URL in the data, as the slide asks. The five photos are Wikimedia Commons stock images, cropped to 640×400 JPEGs in week12_1/img/; their credits are listed below.
  • Prices are numbers and are only formatted at render time with toLocaleString, so step 3 can add them up.
  • The images use alt="" because the product name directly below already says what each one shows.
