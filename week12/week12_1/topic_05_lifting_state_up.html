Lifting state up

Two inputs that show the same temperature cannot each own their value. Move it to the parent, pass it down, and let the children ask for changes.

Below, the parent owns one number — Celsius. The Celsius field writes it directly; the Fahrenheit field converts before writing, and both re-render from the same source. Nothing has to be synchronised, because there is only one copy of the truth.

That is React's one-way data flow: data goes down as props, events come up as callback props, and the parent's state stays the only copy. A child that kept its own copy would have to be kept in step by hand, and the two could drift apart.

The pattern is always the same shape: a value prop down, an onChange prop up. The child never stores the value.
