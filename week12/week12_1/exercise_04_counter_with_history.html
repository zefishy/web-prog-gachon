Counter with history

The in-class code challenge. Two state variables work together: count is the number on screen, and history remembers the last five values so Undo can step back.

The task

Build a Counter component with these features:

1. Display current count (starts at 0). 2. +1 and -1 buttons. 3. Reset button (returns to 0). 4. History: show last 5 count values, e.g. [0, 1, 2, 1, 0]. 5. Undo: clicking Undo sets count to the previous value in history.

Hints: use TWO state variables, count + history (array). Add to history every time count changes. Undo: setCount(history[history.length - 2]), then remove the last item from history.

The component

CounterWithHistory.jsx

function CounterWithHistory() {
  const [count, setCount]     = useState(0);
  const [history, setHistory] = useState([0]);

  function change(next) {
    setCount(next);
    setHistory(h => [...h, next].slice(-5));
  }

  function undo() {
    if (history.length < 2) return;
    setCount(history[history.length - 2]);
    setHistory(h => h.slice(0, -1));
  }

  return (
    <div>
      <h2 aria-live="polite">{count}</h2>
      <p>
        <button onClick={() => change(count + 1)}>+1</button>
        <button onClick={() => change(count - 1)}>-1</button>
        <button onClick={() => change(0)}>Reset</button>
        <button onClick={undo} disabled={history.length < 2}>Undo</button>
      </p>
      <p>History: [{history.join(', ')}]</p>
    </div>
  );
}

How it works

  • One helper for every change. +1, -1 and Reset all go through change(next), which sets the count and appends to the history in one place, so the two can never fall out of step.
  • .slice(-5) keeps the last five. The array is copied with spread first, then trimmed, so the old history is never mutated.
  • Undo reads the second-to-last entry, exactly as the hint says, then drops the last one with slice(0, -1).
  • Undo is disabled when there is nothing to go back to, so the button never looks clickable when it would do nothing.
