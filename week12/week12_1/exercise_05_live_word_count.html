Live word count

One piece of state, one derived value. The textarea is controlled by text, and the word count is worked out from it on every render instead of being stored separately.

The task

Practice: add a live word count to a textarea with useState.

Week 12 Monday slides — Next Session & Resources, Practice

The component

WordCount.jsx

function WordCount() {
  const [text, setText] = useState('');

  const words = text.trim() === '' ? 0 : text.trim().split(/\s+/).length;

  return (
    <div>
      <label htmlFor="wc-text">Write something</label>
      <textarea id="wc-text" value={text} onChange={e => setText(e.target.value)}
                placeholder="Start typing…" />
      <p aria-live="polite">
        <span className="figure">{words}</span> {words === 1 ? 'word' : 'words'}
      </p>
    </div>
  );
}

How it works

  • A controlled textarea. value={text} plus onChange means React state is the single source of truth for what is typed.
  • The count is derived, not stored. A second useState for the count would have to be updated in step with text; computing it during render cannot go stale.
  • Splitting on /\s+/ treats any run of spaces, tabs or newlines as one gap, and trimming first stops an empty box from counting as one word.
