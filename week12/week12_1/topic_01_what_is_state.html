What is state?

A component renders from its props and its state. Props come from outside; state is the memory the component keeps for itself, and changing it is what makes React render again.

Change a plain variable and nothing happens on screen: React has already rendered, and it has no reason to look at that variable again. Wrap the same value in useState and every setter call schedules a new render, which is the whole mechanism behind an interactive interface.
