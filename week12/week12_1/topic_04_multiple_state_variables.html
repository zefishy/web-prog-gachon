Multiple state variables

Several small pieces of state usually beat one big object: each setter stays simple, and a change touches only what depends on it.

A form with a name, an email and a consent flag is three concerns, so it gets three useState calls. The “can submit” answer is not state at all — it is derived from the three, computed during render so it can never fall out of sync.

Watch the derived line: type a name, then an email, then tick the box — the submit button enables only when all three are satisfied, and nothing extra is stored.
