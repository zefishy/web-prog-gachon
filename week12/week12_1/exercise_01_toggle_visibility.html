Toggle visibility

The smallest piece of state there is: one boolean. Clicking the button flips it, React re-renders, and the paragraph appears or disappears without touching the DOM by hand.

The task

Build a component with a button labeled “Show details” / “Hide details”. When clicked, toggle the visibility of a paragraph of text using boolean state.

Lecturer’s Monday study guide — Practice exercise 1

The component

ToggleDetail.jsx

function ToggleDetail() {
  const [isVisible, setIsVisible] = useState(false);
  return (
    <div>
      <button onClick={() => setIsVisible(prev => !prev)} aria-expanded={isVisible}>
        {isVisible ? 'Hide details' : 'Show details'}
      </button>
      {isVisible && (
        <p>React state enables dynamic UIs without page reloads.</p>
      )}
    </div>
  );
}

How it works

  • One boolean, two views. isVisible starts false; the button label and the paragraph are both read from it, so they can never disagree.
  • The functional update. setIsVisible(prev => !prev) flips the latest value rather than the one captured in this render, which is the safe habit from the slides.
  • && renders or skips. When isVisible is false the expression is false, and React renders nothing for it.
  • aria-expanded is one extra prop beyond the lecturer’s version, so a screen reader announces whether the details are open.
