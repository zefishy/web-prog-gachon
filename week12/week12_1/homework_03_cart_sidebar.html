Shopping cart, step 3: Cart sidebar

The cart gets a sidebar. It lists what is in the cart and a total price, and the total is computed from the cart array on every render, not kept in a second piece of state.

3. Cart sidebar. Items + total price, computed from state.

The code

Shop.jsx

const PRODUCTS = [
  { id: 1, name: 'Wireless Earbuds',    price: 89000,  image: 'img/earbuds.jpg' },
  { id: 2, name: 'Mechanical Keyboard', price: 129000, image: 'img/keyboard.jpg' },
  { id: 3, name: 'USB-C Hub',           price: 45000,  image: 'img/usb-hub.jpg' },
  { id: 4, name: 'Laptop Stand',        price: 39000,  image: 'img/laptop-stand.jpg' },
  { id: 5, name: 'HD Webcam',           price: 72000,  image: 'img/webcam.jpg' },
];

const won = n => n.toLocaleString('ko-KR') + ' KRW';

function Shop() {
  const [cart, setCart] = useState([]);

  const inCart = id => cart.some(item => item.id === id);
  const add    = product => setCart(prev => [...prev, product]);
  const remove = id => setCart(prev => prev.filter(item => item.id !== id));

  const total = cart.reduce((sum, item) => sum + item.price, 0);

  return (
    <div className="shop with-cart">
      <ul className="product-grid">
        {PRODUCTS.map(p => (
          <li key={p.id}>
            <img src={p.image} alt="" width="320" height="200" />
            <h3>{p.name}</h3>
            <p className="price">{won(p.price)}</p>
            {inCart(p.id)
              ? <button onClick={() => remove(p.id)}>Remove</button>
              : <button onClick={() => add(p)}>Add to cart</button>}
          </li>
        ))}
      </ul>

      <aside className="cart-panel" aria-label="Cart">
        <h3>Cart ({cart.length})</h3>
        {cart.length === 0
          ? <p className="muted">Your cart is empty.</p>
          : (
            <ul>
              {cart.map(item => (
                <li key={item.id}>
                  <span className="line-name">{item.name}</span>
                  <span className="line-price">{won(item.price)}</span>
                </li>
              ))}
            </ul>
          )}
        <p className="total" aria-live="polite"><span>Total</span><span>{won(total)}</span></p>
      </aside>
    </div>
  );
}

Notes

  • “Computed from state” is the important phrase on the slide. total is a reduce over cart, recalculated each render.
  • Why not useState for the total? Every add and remove would have to remember to update it too. A derived value cannot fall out of sync.
  • The empty state says so in words instead of showing an empty list and a total of zero.
  • On wide screens the sidebar sits to the right of the products; on phones it drops below them.
