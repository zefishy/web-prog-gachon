The brief, in six parts

  • Product list — at least five items, each with a name, a price and an image
  • Add / remove buttons — the state is an array of cart items
  • Cart sidebar — the items and the total, computed from state
  • Quantity controls — a − and a + per item
  • ShoppingCart component — the product list and the cart panel composed
  • Submission — this page, the checklist you are on

Personal page

The brief also asks for some of these features on the personal page: ryanw-portfolio.vercel.app. The rules are the same there — one component owns the data, arrays are copied rather than pushed into, and every total is derived at render time.

The study guide, video and quiz are the lecturer's own pages, linked from the Week 12 deck.

Known limits

  • State resets on reload — nothing is persisted; useEffect is the next session's topic.
  • The cart is client-side only; there is no checkout request.
  • Product images are inline SVG data URIs, so the page works offline — a build with real files would point at image URLs of the same 400 × 260 shape.
