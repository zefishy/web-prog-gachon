Step & fruit loops

Loops: Step Loop & Fruit Loop

Two loop shapes from the class notes. The step loop counts: it knows the start, the end, and the step before it runs once. The fruit loop walks a list: it asks the array for the next item until there are none left. Both end up in the console — press F12 in your browser to see the real DevTools version of the traces below.

Week 5 · from the class notes: “Loops”, and the lecturer's week 5 template (loops.html).

Ready

  • No counter needed. for (let fruit of fruits) hands you one element per pass — the loop variable is the value, not an index.
  • Grow the array mid-demo with the add field: push a new fruit, reset, and the loop walks the longer list. The loop adapts because it reads fruits.length for itself.
