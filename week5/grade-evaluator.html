Grade Evaluator

The conditions snippet from the class notes: an if / else-if chain that turns a score into a letter grade. The interesting part is not the grades — it is the order. The chain checks from the top down and stops at the first true condition, so the thresholds must run highest-first. Drag the slider below and watch each condition get tested and skipped, exactly as the interpreter does it.

Week 5 · from the class notes: “Conditions (if / else)”, and the lecturer's week 5 template (grade-evaluator.html).

How it works

  • Top-down, first true wins. The chain tests >= 90, then >= 80, then >= 70; the moment one is true, its block runs and everything after is skipped.
  • Order is the logic. Written bottom-up, a score of 95 would hit >= 70 first and print 'C' — same conditions, wrong order, wrong answer.
  • Boundaries are inclusive. >= 90 means exactly 90 is an 'A' — try it on the slider; 89 is a 'B'.
  • else needs no condition. It catches everything the chain fell through — here, any score below 70.
