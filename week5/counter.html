How it works

    1

    One state variable

    let count = 0 lives in the script, not in the page — the number on screen is just a picture of it.

    2

    Parameterized handlers

    All three buttons share one change(amount) function; each button passes 1, -1, or calls reset() instead.

    3

    DOM update

    document.getElementById('count').textContent = count writes the state back into the page after every change.
