addEventListener

Nothing happens until the event fires.

Click the button, then type in the field. Every event is written to the log below as it arrives.

    The snippet

    const btn = document.querySelector('#my-btn');

btn.addEventListener('click', function () {
  console.log('Button was clicked!');
});

// 'input' fires on every change, not just on blur
const inp = document.querySelector('input');
inp.addEventListener('input', () => {
  console.log('Input value: ', inp.value);
});
