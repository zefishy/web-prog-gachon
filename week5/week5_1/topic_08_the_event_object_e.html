The event object (e)

The callback is handed a description of the event.

Click anywhere in the box, then press a key while the page has focus.

The snippet

btn.addEventListener('click', (e) => {
  console.log(e.type);       // 'click'
  console.log(e.target);     // the element clicked
  console.log(e.target.id);  // its id attribute
});

document.addEventListener('keydown', (e) => {
  console.log(e.key);        // 'Enter', 'a', 'ArrowUp' ...
});
