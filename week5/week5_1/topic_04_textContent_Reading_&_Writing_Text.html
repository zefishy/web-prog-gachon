textContent: reading & writing text

Change text without ever parsing it as HTML.

The snippet sets this heading to a string full of angle brackets. Because textContent does not parse HTML, the tags show up literally instead of turning bold:

Hello

That is the safety feature, not a bug: user input can never become markup through textContent.

The snippet

const title = document.querySelector('#title');

console.log(title.textContent);          // read
title.textContent = 'Welcome to Web Programming!';

title.textContent = '<b>Not bold</b>';   // shown as text, not markup
