innerHTML: power & danger

Same box, two ways to fill it. Type something and compare.

The payload below is the classic test string. Rendered as HTML it becomes a live image element with an event handler; rendered as text it stays inert.

The innerHTML button may show a broken image or fire the alert; the textContent button always prints the string.

The snippet

const box = document.querySelector('#box');

// Fine: you control the string
box.innerHTML = '<strong>Bold</strong> and <em>italic</em>';

// Dangerous: the string comes from a user
box.innerHTML = userInput;   // can inject markup and scripts

// Safe: same string, no parsing
box.textContent = userInput;
