querySelector & querySelectorAll

CSS selectors, but for JavaScript.

querySelector stops at the first match. querySelectorAll returns a NodeList, so you can loop over every match at once — here it recolours all three list items.

A heading with an id

A paragraph with class="card active"

  • First list item
  • Second list item
  • Third list item

The snippet

const btn   = document.querySelector('button');      // first <button>
const title = document.querySelector('#main-title'); // by id
const card  = document.querySelector('.card.active'); // both classes

document.querySelectorAll('.list-item').forEach(item => {
  item.style.color = 'blue';
});
