createElement & appendChild

Build first, insert second.

The snippet below adds three rows to this list using three different insertion methods.

  • Original item

End state: the created node is prepended, an HTML string is appended, and the original item sits in the middle.

The snippet

const li = document.createElement('li');   // 1. create
li.textContent = 'New item!';               // 2. configure
li.classList.add('list-item');

const ul = document.querySelector('#my-list');
ul.appendChild(li);                         // 3. insert at end
ul.prepend(li);                             // or at the start

ul.insertAdjacentHTML('beforeend', '<li>Another item</li>');
