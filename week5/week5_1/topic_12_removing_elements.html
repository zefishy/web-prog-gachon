Removing elements

Remove the node, not just its contents.

The snippet removes the first paragraph outright, then wires the delete buttons in the list.

This paragraph is removed by the script.

  • First row
  • Second row

The snippet

const item = document.querySelector('.to-delete');
item.remove();                       // gone, and out of the flow

const list = document.querySelector('#my-list');
list.addEventListener('click', (e) => {
  if (e.target.matches('.delete-btn')) {
    e.target.closest('li').remove(); // remove the whole row
  }
});
