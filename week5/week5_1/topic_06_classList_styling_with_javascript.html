classList styling

JavaScript flips the class; CSS decides what the class looks like.

Press the buttons and watch the box. The styling lives in the stylesheet, so it can be themed and reused.

A plain box

Current class list: (empty)

The snippet

const box = document.querySelector('.card');

box.classList.add('highlighted');
box.classList.remove('highlighted');
box.classList.toggle('dark');        // on if off, off if on
box.classList.contains('active');    // true / false

/* CSS decides the look:
   .highlighted { background: yellow; font-weight: bold; } */
