Build a login form

The plainest useful form: two labelled fields, a remember-me checkbox, and a submit button — every control reachable by Tab and readable by a screen reader.

The autocomplete values let a password manager fill both fields in one click: email for the address, current-password here (and new-password on a sign-up form).

Note: /login is a placeholder action — there is no server behind it, so submitting would only navigate away. The form exists to practise the markup.
