Add required & pattern attributes

A Gachon registration form where every rule is declared in the markup: the browser refuses to submit it until the student ID is nine digits and the phone number matches the Korean format.

  • required on all four — submitting an empty form stops on the first one
  • pattern="\d{9}" on the ID, with title as the message a person actually sees
  • pattern on the phone number, so the hyphens have to be there
  • type="email" on the address — the browser checks the shape for free

novalidate is on here only so this demo can show its own summary instead of the browser bubble; take it off and the built-in messages take over.

Note: /register is a placeholder action — there is no server behind it.
