About this library

I'm learning practical web design and development through coursework and hands-on exercises. Every page here is one of those exercises or topic demos, grouped by the week it belongs to.

I care about clean interfaces, semantic HTML, and accessibility, so I try to build pages that are polished, responsive, and easy for everyone to use.

Role
Exchange student at Gachon University
Field
Web programming and front-end web design
Focus
HTML, CSS, JavaScript, responsive layout, visual styling, and user-friendly interface design
Interests
Clean UI design, semantic HTML, modern CSS, accessibility, and building functional web pages
Goal
Create polished, responsive, and accessible websites with strong visual design and a good user experience
