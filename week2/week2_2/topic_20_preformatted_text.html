Preformatted text

Whitespace kept exactly as typed.

Normally HTML collapses runs of spaces and newlines. pre stops that, so indentation survives — essential for code and ASCII art.

function greet(name) {
  return 'Hello, ' + name;
}

The indentation above is real characters, not CSS.

The markup

<pre><code>function greet(name) {
  return 'Hello, ' + name;
}</code></pre>
