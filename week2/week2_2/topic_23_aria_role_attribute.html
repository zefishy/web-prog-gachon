The ARIA role attribute

The last resort before a native element.

A button already has the button role. Adding role="button" to a div changes what it is announced as, but not how it behaves — you still have to add tabindex and key handling yourself.

The first rule of ARIA is not to use ARIA when HTML already says it.

This div is announced as a note because of its role.

The markup

<div role="note">Announced as a note.</div>

<!-- Unnecessary: button already has the role -->
<button role="button">Save</button>
