Images: img and src

One void element, one required attribute.

The src is a URL like any other link target. A relative path resolves from the current document, which is why moving a file breaks the image.

This image is an inline SVG data URI, so it cannot go missing.

The markup

<img src="photo.jpg" alt="A white circle on a green square"
     width="120" height="80">
