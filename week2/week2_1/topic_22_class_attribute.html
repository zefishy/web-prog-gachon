The class attribute

Reusable, repeatable, space-separated.

Unlike id, a class may appear on any number of elements and an element may have several. CSS and JavaScript both match on it.

A paragraph with class="badge"

Another one, same class

Both paragraphs pick up the same rule.

The markup

<p class="badge">First</p>
<p class="badge warning">Second, two classes</p>
