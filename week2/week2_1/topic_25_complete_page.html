A complete page

Every piece from the first 24 topics, in order.

Doctype, html with lang, head with charset and title, body with a heading and a paragraph. That is a valid document — everything else is content.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My first page</title>
</head>
<body>
  <h1>Hello Gachon!</h1>
  <p>This is my first web page.</p>
</body>
</html>

This page you are reading is built the same way.
