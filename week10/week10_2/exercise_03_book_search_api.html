Book search API

Searching for books with an API-powered web app. The app on this site uses the Open Library API and is a static page, so it deploys to GitHub Pages as it is.

The task

Build a page that searches for books through a public API and shows the results, then put it on GitHub Pages. The app needs no server, because the browser calls the API directly with fetch().

The app

The Book Search App is in Week 7. It searches the Open Library, shows results as cards with covers, and keeps working when the API is slow or offline, using loading skeletons, a timeout, retries and a saved cache.

  • Open the Book Search App
  • Open Library search API documentation

Deploying it

GitHub Pages serves static files over HTTPS, so a fetch() call to a public API works from a Pages site. The page needs index.html at the root of the deployed branch and a public repository. The steps are the same as in the deployment report.
