Personal portfolio

A published portfolio website: one page with my name, photo, bio, skills and links to course projects, deployed on GitHub Pages.

The task

Create a personal portfolio repo on GitHub called ‘portfolio’. Add index.html with your name, photo, bio, skills, and links to 2–3 course projects. Make at least 5 meaningful commits with clear messages.
